#**E-VOTEX - An Online Voting System**
  A console-based voting application developed using C++ OOP and Data Structures & Algorithms.

##**Problem Description**
Traditional voting can be slow and error-prone. This project provides a digital system for voter registration, authentication, secure voting, candidate management, and automatic result calculation.

 ###**Features**
Admin and Voter Login
Voter Registration
Candidate Management
Secure Vote Casting
Duplicate Vote Prevention
Automatic Vote Counting
Winner Declaration
Search & Sort
File Handling

###**Concepts Used**
OOP: Classes, Objects, Encapsulation, Inheritance, Constructors
DSA: Linked Lists, Hashing, Searching, Sorting
